尚未登入驗證
⚠️ Firebase 雲端資料庫同步失敗：權限不足或尚未建立 Firestore 資料庫
請至 Firebase Console（專案 homework-warning-7c04d）→ 左側選單「建構 > Firestore Database」確認已建立資料庫，並於「規則 (Rules)」分頁貼上以下規則後點擊「發佈」： 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /midterm_warning_roster/{docId} {
      allow read, write: if true;
    }
  }
}
請輸入您的教師或課程代碼（不區分大小寫）；登入後將僅過濾並顯示您任教之班級與科目名冊。
驗證通過後可進入後台進行 .xlsx 檔案匯入、下載匯入範本、全校 13 欄管理與批次補登代碼。

系統作業規範與即時同步說明

Firebase 即時同步
  • 1. 跨裝置與多分頁雙向即時同步 串接 Firebase Cloud Firestore（專案 homework-warning-7c04d）與跨分頁即時通道，任何教師勾選或匯入異動皆會即時同步。
  • 2. 完整 13 項資料庫欄位 班級、學號、姓名、科目、教師、無作業、已繳交、未繳交、睡覺、缺交內容、其他建議、最後修改時間、最後修改者。
  • 3. 快速選取份數與即時稽核 「已繳交」勾選框緊鄰「無作業」之後、「未繳交」之前；「未繳交」提供 0 份至 6 份以上下拉選取，儲存時自動紀錄時間與登入代碼。
  • 4. 支援純 5 欄 XLSX 匯入與內建備援 Excel 僅需「班級、學號、姓名、科目、教師」即可匯入，亦可一鍵匯出為內建程式碼備份。
